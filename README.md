# Gladvale Farm Map

Interactive farm map for Gladvale Farms (GV1 + McFarlane, 2026 survey).

- `index.html` – landing page to choose a farm (GV2, GV3, GV4 and GV6 coming soon)
- `gv1.html` – the GV1 map, 102 paddocks incl. McFarlane (map library and farm data are built in)
- `robots.txt` – asks search engines not to list the site

Data: Southland Farm Mapping survey (June 2026); tile drains from FieldMAP export (Aug 2025).
Imagery: Esri World Imagery.
